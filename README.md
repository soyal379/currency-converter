# Currency Converter

A simple and user-friendly currency converter web application that supports all countries and their currencies.

## Overview

This project provides an easy-to-use interface to convert currencies between different countries. The application displays all available countries and their respective currency information.

## Features

- 🌍 **All Countries Supported** - Browse currency information for all countries worldwide
- 💱 **Real-time Conversion** - Convert currency amounts between different countries
- 🎨 **Clean Interface** - User-friendly and responsive design
- ⚡ **Fast Performance** - Quick and efficient conversions

## Technology Stack

- **HTML** (16.9%) - Markup structure
- **CSS** (41.5%) - Styling and layout
- **JavaScript** (41.6%) - Logic and interactivity

## How to Use

1. Open `index.html` in your web browser
2. Select the country/currency you want to convert from
3. Select the country/currency you want to convert to
4. Enter the amount to convert
5. View the converted result instantly

## Installation

1. Clone the repository:
```bash
git clone https://github.com/soyal379/currency-converter.git
cd currency-converter
```

2. Open the application:
   - Simply open `index.html` in your web browser
   - No additional dependencies required
